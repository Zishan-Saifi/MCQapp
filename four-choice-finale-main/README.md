Dev Quiz — Interactive Quiz Web App

An interactive web development quiz application built with React. Test your knowledge of React, JavaScript, and HTML/CSS through a quick-fire quiz with a timer and score tracking.

🌐 Live Demo

Try the app: https://mcq-quiz-app-wine.vercel.app/

✨ Features

- Multiple Topics: React, JavaScript, and HTML/CSS.
- Timed Questions: 30 seconds to answer each question.
- Interactive Quiz: One question displayed at a time.
- Score Tracking: Test your knowledge and track your performance.
- 12 Questions: A quick quiz session with 12 questions.
- Fresh Question Order: Questions appear in a different order on each attempt.
- Responsive Design: Designed for a convenient web experience.
- Easy to Use: Simple interface for an engaging quiz experience.

🛠️ Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Vercel (Deployment)

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

- Node.js and npm installed
- Git installed
- Visual Studio Code or another code editor

Installation

1. Clone the repository:
   
   git clone https://github.com/Zishan-Saifi/MCQ

2. Navigate to the project folder:
   
   cd mcq-quiz-app

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.

Note: These commands assume the project uses a standard Vite-based React setup. Adjust them if your project uses a different setup.
